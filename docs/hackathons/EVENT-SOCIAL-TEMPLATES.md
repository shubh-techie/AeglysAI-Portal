# Event announcement asset specification and reusable templates

Recorded 2026-10-26. PLANNED design/export artifacts; no official partner graphics or copy approved. The Portal has no image-export infrastructure; no rendering engine is introduced. Use an existing design editor, then obtain separate asset/channel approval. Portal scheduling does not publish social posts.

Editable source templates: [square](templates/event-square.svg), [landscape](templates/event-landscape.svg), [portrait](templates/event-portrait.svg), [story](templates/event-story.svg). These remain documentation assets, not public announcements. Edit text, manually wrap copy and insert only approved imagery in a vector editor; export PNG at the native dimensions. The long review label should be removed only after final approval.

Reusable partner-announcement composition, adapted to each canvas: approved AeglysAI mark and event name at top; category/verified official role; approved partner name or supplied approved logo centered; exact approved announcement copy; approved Portal URL/date footer. Use existing navy background (#080f1c), cyan (#64e1ed), white text (#edf2f5), system sans-serif, generous line height. Avoid simulated signatures, logos, endorsements or confirmations. Use portrait/square image crops only with permission; preserve organization logos using contain. Target text contrast at least 4.5:1 and avoid information conveyed only by color.

Reusable text template (fill only approved fields):

> [Event name] — [verified role/category]\
> [Approved display name]\
> [Exact approved announcement copy]\
> [Approved public event URL]

Speaker/judge/mentor variant: replace organization logo area with approved headshot and name/title; include only verified affiliation and approved session. Participant/team variant: omit personal contacts/member roster and include only explicitly consented public display information. Event Announcement variant: headline, approved copy, announcement date and canonical public link. Optional content is omitted, never filled with invented placeholders in a final export.

Asset handoff checklist: source record/event ID, intended format, exact approved copy, approved image path and alt/accessible caption, branding/content approval, channel-specific consent, publish date/time/timezone, reviewer and withdrawal owner held privately. Never export from raw registration responses. Dates on the three draft partner records are proposed announcement dates, not approval. Naming: `[event-id]-[record-id]-[width]x[height]-review.png`; remove review suffix only after approval. Review at phone scale and provide an accessible text caption. Do not commit private evidence or unapproved final graphics.
